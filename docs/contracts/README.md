# Academic proposals

Version 1 of `habits.academic-plan` is shared with [habits-mcp](https://github.com/ravel7524/habits-mcp). The schema and fictional [two-course example](two-course-exams.json) are included here so this repository remains independent. The same example is a classpath test resource under core/src/test/resources/assistant. Keep the copies byte-identical when updating the shared contract.

Proposals add semester/course/assessment records and linked preparation tasks after review. Known source dates, optional times and source IANA timezone are required; unknown preparation dates or exam times remain omitted. Reusing a proposal ID with changed content is rejected. Preview, confirmation, replay protection and guarded Undo belong to the phone. Current assistant commands do not change screens, habits or app settings.
