# Preview verification

The published 0.1.0 APK is the exact development build verified on 3 October 2026. On 5 October its SHA-256 was rechecked, application/runtime source was exported unchanged, and all 65 contract/workspace/connection tests passed from this standalone project. Test fixtures now load from classpath resources instead of another repository.

Earlier acceptance on an API 36 ARM64 emulator included five passing Compose UI workflows and real private pinned-TLS/HMAC pairing, selected context sharing, fetching/reviewing/saving proposals, applied receipts, and refresh → process restart → file reopening → guarded Undo → undone receipt. Unknown exam times stayed absent and preparation remained separate from exam completion. The same-proposal replay did not create duplicates, stale preview preserved intervening work, and local task/habit facts appeared in the Evening summary.

Publication does not claim a fresh emulator run. Physical phones/LAN routing, all-language/dark/accessibility UI, power-loss durability and Android LLDB acceptance remain open. Android runtime verification used adb, UI hierarchies and instrumentation; native LLDB was unavailable. [The first standalone CI run](https://github.com/ravel7524/habits-android/actions/runs/37318116223) passed portable tests and app/test-APK compilation; it does not replace those runtime checks.

The release is debug-signed. The original private signing key is not shipped, and a retained private copy has not been confirmed. Future same-package update compatibility remains unestablished until signing continuity is recovered or a supported migration is chosen. Export local data before any reinstall.
